# Bob-A-Thon: PII Log Leak Detector & Business Observability

> **IBM Bob × Developer Kaki Hackathon**
> _Enterprise Risk Mitigation, Autonomously Generated._

---

## The Problem

Malaysian financial institutions face constant pressure under **BNM RMIT** and **PDPA** compliance mandates. Yet one of the most common audit failures is deceptively simple: a developer accidentally logs a raw object or exception payload containing a customer's **National Registration Identity Card (NRIC)** number or a **credit card number** in plaintext.

These tokens propagate instantly to centralised log aggregators — Elastic, Splunk, IBM QRadar — where they persist for months. Manual code reviews routinely miss them. By the time a compliance audit flags the leak, retroactive remediation costs are already in the hundreds of developer-hours, with regulatory fines potentially running into the millions.

**This is not a hypothetical risk. It is a weekly occurrence in production environments.**

---

## Objective

Shift telemetry hygiene **left** — intercept and mask PII at the application runtime layer, _before_ it reaches any centralised infrastructure, while providing compliance and engineering leadership with real-time observability into every interception event.

### Components — all generated by IBM Bob

| File | Purpose |
|------|---------|
| [`scanner.py`](scanner.py) | Scans log files / raw text for Malaysian NRICs and PCI credit card numbers. Returns structured `PIIFinding` objects. |
| [`sanitizer.py`](sanitizer.py) | `logging.Filter` subclass that masks PII in real-time before any handler writes to disk or streams to a remote aggregator. |
| [`exporter.py`](exporter.py) | Prometheus metrics exporter on `:8000/metrics`. Exposes interception counters, scan latency histograms, and instance info. |
| [`grafana/dashboard.json`](grafana/dashboard.json) | Grafana dashboard model with 9 panels covering North Star KPIs, interception rate time series, and scan latency gauges. |
| [`bob_run.sh`](bob_run.sh) | End-to-end orchestration: invokes IBM Bob for each artefact, starts the exporter, imports the Grafana dashboard, commits, and pushes. |

## Quick Start

```bash
# 1. Clone
git clone https://github.com/ctin0018/Bob-A-Thon.git && cd Bob-A-Thon

# 2. Install dependencies
pip install prometheus_client

# 3. Run the orchestration script (requires IBM Bob CLI)
chmod +x bob_run.sh
GRAFANA_API_KEY=<your-key> ./bob_run.sh

# 4. Or start just the exporter
python exporter.py

# 5. Drop the sanitizer into your application
python - <<'EOF'
import logging
from sanitizer import install_global_filter

install_global_filter()

logger = logging.getLogger("demo")
logger.warning("Customer NRIC: 880101-14-5678 paid with card 4111111111111111")
# Output: Customer NRIC: 880101-**-**** paid with card ****-****-****-1111
EOF
```

## Grafana Dashboard — Import

1. Open Grafana → **Dashboards → Import**
2. Upload `grafana/dashboard.json`
3. Select your **Prometheus** datasource
4. Click **Import**

The dashboard auto-refreshes every **10 seconds** and is pre-configured for the **Asia/Kuala_Lumpur** timezone.

### PromQL Reference

| Panel | Query |
|-------|-------|
| Total PII Breaches Prevented | `sum(pii_log_interceptions_total)` |
| NRIC Tokens Masked | `pii_log_interceptions_total{pii_type="NRIC"}` |
| Credit Card Tokens Masked | `pii_log_interceptions_total{pii_type="CREDIT_CARD"}` |
| Developer Hours Saved | `sum(pii_log_interceptions_total) * 0.05` |
| Interceptions / min | `rate(pii_log_interceptions_total[1m]) * 60` |
| Scan latency p50 | `histogram_quantile(0.50, sum(rate(pii_scan_duration_seconds_bucket[5m])) by (le))` |
| Scan latency p99 | `histogram_quantile(0.99, sum(rate(pii_scan_duration_seconds_bucket[5m])) by (le))` |
